**********
Render a report as text.

By default, all the nested lines in the generated report are indented with ``'  '`` (two spaces) before they are written.

When syncing, the parser handles annotations and types that contain ``, default=`` in their own text.

A literal longer than the line stays whole: ``x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x x`` and is not split.

A literal split by an earlier version is joined again, e.g. ``Generator[T,
None, None]`` or ``Iterator[T]`` in this sentence.

Parameters
----------
report : str
    The report to render. All of its nested lines are always indented with ``'  '`` (two spaces).
